\section{Existing tools, libraries, papers with code}
I used \href{https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html}{scikit-learn} for TF--IDF, Logistic Regression and scoring; \href{https://github.com/openai/tiktoken}{tiktoken} for the \texttt{o200k\_base} BPE features; and \href{https://huggingface.co/docs/transformers/en/index}{Hugging Face Transformers} with PyTorch for DistilBERT. The pretrained checkpoint is \href{https://huggingface.co/distilbert/distilbert-base-uncased}{\texttt{distilbert-base-uncased}}. Python's \href{https://docs.python.org/3.12/library/unicodedata.html}{\texttt{unicodedata}} provides normalization. The lock file records the package versions used by the notebooks.

Published implementations provide useful reference points: Boucher et al. release their \href{https://github.com/nickboucher/imperceptible}{attack code and experiments}, and Cooper et al. provide \href{https://github.com/pcoopercoder/The-Lies-Characters-Tell}{homoglyph augmentation code and normalization prompts}. The TREC authors also publish preprocessing examples and feature scripts alongside the data. I implemented the restricted attacks and deterministic defenses directly in the notebooks so that their behavior is easy to inspect.

Notebooks 00--06 contain the local experiments; notebook 07 contains the "last minute" Jev comparison. The submission includes the saved metric tables, figures, report source and compiled PDF. Datasets, fitted checkpoints and prediction caches must be recreated or supplied separately when rerunning the notebooks.
