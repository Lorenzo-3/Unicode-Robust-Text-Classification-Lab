A sentence can look almost unchanged yet become difficult for a text classifier to read. This project tests that gap using Unicode substitutions and insertions on BANKING77 and TREC. Three TF--IDF classifiers isolate the role of word, character and BPE features; fine-tuned DistilBERT provides a pretrained reference. Character features retain the most performance at the primary 20\% attack strength, while DistilBERT's robustness depends strongly on the attack family. Simple preprocessing recovers much of the lost performance, and a restricted confusable map almost restores the clean scores within the experiment's restricted attack set. These findings support the usefulness of targeted input handling, with clear limits on generalization beyond English-only use.
